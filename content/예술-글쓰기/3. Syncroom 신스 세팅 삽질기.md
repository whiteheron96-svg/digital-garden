# 맥에서 야마하 SYNCROOM에 신디사이저 소리 넣기 — 삽질기와 정답

> **TL;DR** — 하드웨어 신스는 오디오 인터페이스(스칼렛)에 직접 꽂고 SYNCROOM 입력을 그 인터페이스로 잡으면 끝. **BlackHole도 MainStage도 필요 없다.** 나는 이 사실을 모르고 반나절을 삽질했다.

## 목표

MacBook + 야마하 SYNCROOM으로 온라인 합주를 하는데, **신디사이저(+ MainStage) 소리를 합주방에 내보내고 싶었다.** 마이크는 안 쓰고 건반만.

## 1단계: 첫 벽 — "SYNCROOM 입력에 집합장치(Aggregate)가 안 뜬다"

여러 오디오를 묶으려고 macOS의 **집합장치(Aggregate Device)**를 만들었는데, **SYNCROOM 입력 목록에 안 나타났다.** 알고 보니 SYNCROOM은 집합장치·다중출력장치를 입력으로 안 잡는다. 그래서 가상 오디오 케이블인 **BlackHole**로 방향을 틀었다.

→ 여기서부터가 진짜 삽질의 시작이었다.

## 2단계: MainStage에서 소리가 아예 안 남

BlackHole로 라우팅을 짜다 보니 이번엔 **MainStage 자체에서 소리가 안 났다.** 믹서 미터는 움직이는데 어느 출력으로도 무음. 확인해보니 원인은:

- **MainStage는 입력·출력 오디오 장치가 다르면 무음이 될 수 있다.** (입력=스칼렛, 출력=다른 장치)
- 여러 번 장치를 갈아끼우면 오디오 엔진이 굳어버린다. → 재시작/장치 재선택으로 풀림
- 참고로 다른 앱(음악 앱)은 멀쩡했으니 시스템 오디오 문제는 아니었다

## 3단계: 소리는 나는데 SYNCROOM으로 안 넘어감

MainStage 소리는 헤드폰으로 나는데, **SYNCROOM 입력 미터는 죽어 있었다.** 설정 파일을 열어보니 MainStage 출력이 **BlackHole이 아니라 내장 헤드폰**으로 잡혀 있었다. 출력을 BlackHole로 바꿔도 여전히 안 넘어감.

## 4단계: 핵심 함정 — BlackHole은 클럭이 없다

BlackHole을 직접 테스트(루프백)해보니 **신호가 통과하지 않았다.** 이유:

- **BlackHole은 자체 하드웨어 클럭이 없는 가상장치**라, 단독으로 출력하면 기준 클럭이 없어 실제 샘플이 안 넘어간다
- 그래서 집합장치(클럭소스=스칼렛, BlackHole 드리프트 보정)로 클럭을 물려줘야 한다
- 집합장치는 채널을 나눠 보내고(스칼렛 1-2, BlackHole 3-4), 다중출력장치는 같은 소리를 양쪽에 복사한다 — 용도가 다르다

여기까지 오니 헤드폰 모니터는 되는데 SYNCROOM은 계속 안 됐다.

## 5단계: 깨달음 — 하드웨어 신스면 이 모든 게 필요 없다

문득 든 생각: **"하드웨어 신스는 실제 오디오 케이블로 소리가 나오는데, 왜 가상 케이블(BlackHole)이 필요하지?"**

정답이었다.

- **하드웨어 신스** → 물리 출력이 있으니 인터페이스에 직접 꽂으면 됨. BlackHole 불필요
- **소프트웨어 신스(가상악기)** → 물리 출력이 없어서 그때만 BlackHole이 "가상 케이블"로 필요

나는 하드웨어 신스를 쓸 거였으니, **BlackHole도 MainStage 라우팅도 전부 버리면 됐다.**

## 최종 정답 (하드웨어 신스)

```
신디사이저 → 스칼렛 솔로 인풋 (INST 버튼 OFF, 라인레벨)
SYNCROOM   입력  = Scarlett Solo
           출력  = Scarlett Solo
           버퍼  = 256
헤드폰 → 스칼렛
```

## 마지막 잔손질

- **왼쪽만 들림** → L/MONO 한 잭이라 모노. SYNCROOM "스테레오로 취급 OFF" + 입력 채널을 신스가 들어온 채널로 지정해 가운데 정위
- **"틱틱" 잡음** → 버퍼 128이 너무 낮아서. **256으로 올리니 사라짐**
- **잡음/왜곡** → 스칼렛 INST 버튼 OFF, 게인은 낮추고 신스 볼륨을 키우기

## 교훈

1. **SYNCROOM은 집합장치를 입력으로 안 잡는다** — 가상 케이블이 필요하면 BlackHole을 직접 지정
2. **BlackHole은 클럭이 없다** — 단독 출력은 안 되고, 실제 인터페이스와 묶어 클럭을 줘야 한다
3. **MainStage는 입출력 장치를 맞춰야** 무음이 안 생긴다
4. **하드웨어 신스라면 가상 케이블이 애초에 필요 없다** — 인터페이스에 직접 꽂고 SYNCROOM 입력으로
5. **틱틱 잡음은 버퍼를 올려라** (128→256)

가장 단순한 답이 정답이었다. 소프트 신스까지 합주에 넣어야 할 때만 BlackHole을 다시 꺼내면 된다.
