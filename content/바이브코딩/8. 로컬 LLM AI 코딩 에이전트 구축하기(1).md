# 로컬 LLM으로 AI 코딩 에이전트 구축하기 (Ollama + Qwen + Aider)

## 왜 로컬 LLM을 사용할까?

회사 내부 데이터나 민감한 프로젝트를 다룰 때는 외부 API 사용이
부담스러울 수 있다. 로컬 LLM은 AI 모델을 내 컴퓨터에서 직접 실행하므로
인터넷을 통해 데이터를 외부로 전송하지 않고도 AI를 활용할 수 있다.

------------------------------------------------------------------------

# Ollama란?

Ollama는 로컬 LLM을 실행하는 프로그램이다.

예시:

``` bash
ollama run qwen2.5:3b
```

Ollama는 모델을 실행하는 역할을 담당한다.

------------------------------------------------------------------------

# Qwen은 무엇을 할 수 있을까?

Qwen은 다음과 같은 작업을 수행한다.

-   코드 작성
-   코드 설명
-   코드 수정

하지만 **Python 코드를 직접 실행하지는 않는다.**

즉,

``` text
사용자
   ↓
Qwen
   ↓
Python 코드 생성
```

실제 실행은 Python이 담당한다.

------------------------------------------------------------------------

# ChatGPT나 Claude Code는 왜 실행까지 할까?

LLM 뒤에 **에이전트(Agent)** 가 있기 때문이다.

``` text
사용자
   ↓
LLM
   ↓
Python 실행
   ↓
결과 확인
   ↓
오류 수정
```

------------------------------------------------------------------------

# Aider란?

Aider는 AI 코딩 에이전트이다.

예를 들어 프로젝트 폴더 안에서

> ".xlsx를 읽어서 Plotly 그래프를 추가해줘."

라고 요청하면

-   프로젝트 파일을 읽고
-   필요한 파일을 수정하고
-   Python 코드를 생성하며
-   여러 파일을 동시에 관리한다.

Git과 함께 사용하면 변경 이력도 관리할 수 있다.

------------------------------------------------------------------------

# 회사 데이터는 안전할까?

## Ollama + 로컬 모델 사용

``` text
회사 데이터
      │
      ▼
Aider
      │
      ▼
Ollama
      │
      ▼
Qwen (내 PC)
```

외부 API를 사용하지 않는다면 데이터는 PC 내부에서만 처리된다.

반면 OpenAI API와 같은 클라우드 모델을 연결하면 프롬프트와 일부 코드가
외부 서버로 전송될 수 있으므로 회사 보안 정책을 확인해야 한다.

------------------------------------------------------------------------

# 추천 개발 환경

MacBook

-   Ollama
-   Aider
-   VS Code
-   Python
-   Git

Samsung T7 SSD

-   Qwen 모델
-   AI 프로젝트
-   데이터셋

모델은 용량이 크므로 외장 SSD에 저장하는 것이 효율적이다.

Aider는 수십\~수백 MB 수준의 Python 프로그램이라 내부 SSD에 설치해도
충분하다.

------------------------------------------------------------------------

# 설치 순서

## 1. Ollama 설치

``` bash
ollama
```

## 2. 모델 설치

``` bash
ollama pull qwen2.5:3b
```

또는

``` bash
ollama pull qwen2.5-coder:3b
```

## 3. Aider 설치

``` bash
python3 -m pip install aider-install
aider-install
```

## 4. 프로젝트 생성

``` bash
mkdir agri-analysis
cd agri-analysis
git init
```

## 5. 실행

``` bash
aider --model ollama_chat/qwen2.5-coder:3b
```

# 마무리

Ollama, Qwen, Python, Git, Aider를 함께 구성하면 로컬 환경에서 안전하게
데이터를 분석하고, 코드를 작성하고, 실행하고, 수정하는 AI 개발 환경을
구축할 수 있다.

특히 기업 내부 데이터나 연구 프로젝트처럼 외부 반출이 어려운 환경에서는
매우 유용한 선택지가 될 수 있다.
