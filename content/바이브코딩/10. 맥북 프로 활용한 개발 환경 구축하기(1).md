

## 1. 목표

기존에 보유한 MacBook Pro를 24시간 실행되는 AI 개발 서버로 활용하여, 연구·데이터 분석·자동화 업무를 수행할 수 있는 환경을 구축한다.

### 주요 목표

- Docker 기반 개발 환경 구축
- Codex / Claude Code 기반 AI 개발 환경 구축
- Slack 기반 작업 알림 시스템 구축
- 연구 자동화 및 데이터 분석 자동화
- 개인정보를 보호하는 작업 환경 구성
- 향후 Mac mini 또는 Linux 서버로 쉽게 이전 가능한 구조 설계

# 4. Docker 활용 목적

Docker는 AI Agent 자체가 아니라 **개발 환경을 안정적으로 운영하기 위한 플랫폼**이다.

서비스별 환경을 독립적으로 운영한다.

```text
Docker

├── PostgreSQL
│      작업 이력 저장
│
├── Redis
│      작업 큐
│
├── Supervisor
│      전체 작업 제어
│
├── Dashboard
│      웹 상태 확인
│
└── Slack Notifier
       알림 전송
```

장점

- 환경 충돌 방지
- 재설치 용이
- 다른 컴퓨터로 이전 가능
- 서비스별 독립 운영

# 7. 개인정보 보호

원본 데이터와 작업 데이터를 분리한다.

```text
MacBook Pro

/private

    원본 데이터

    Docker 접근 불가

--------------------------

/workspace

    비식별 데이터

    Docker 접근 가능
```

원칙

- 원본 데이터 수정 금지
- 작업은 복사본에서 수행
- 개인정보 포함 여부 사전 검사
- 결과만 Output 폴더 저장
