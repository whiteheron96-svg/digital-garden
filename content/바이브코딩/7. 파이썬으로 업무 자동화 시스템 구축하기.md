
교육포털에서 수료증을 자동으로 다운로드 하기 위해 시스템을 구축할 필요가 있었다. 
찾아보니, 화면에 사람별로 뜨는 수료증 버튼을 자동으로 클릭해서 수료증을 다운로드 해주고, 그 PDF 파일을 jpg로 변경해서 문자 API 서비스를 통해 자동으로 해당 이미지가 발송되게 할 수 있었다. 

특히나, Streamlit 이란 프로그램으로 웹앱을 만들면, 내가 아니라 다른 직원들도 해당 앱에 명단을 업로드하면 똑같이 자동으로 수료증을 보낼 수가 있었다. 

이렇게 하면 결과도 엑셀로 정리해준다.

# Python으로 나만의 업무 자동화 시스템 만들기 (1) 전체 구조 설계

## 들어가며

반복 업무가 많아질수록 사람은 실수하고 지치게 된다.

이번 프로젝트에서는 교육포털의 수료증을 자동으로 다운로드하고, 수료자별로 파일명을 변경한 뒤, 문자 발송까지 자동화하는 시스템을 구축했다.

이 과정에서 사용한 기술은 다음과 같다.

- Python
    
- Streamlit
    
- Playwright
    
- Pandas
    
- PDF2Image
    
- 알리고 API
    

## 전체 구조

```text
사용자
 ↓
Streamlit
 ↓
Python
 ├─ Pandas
 ├─ Playwright
 ├─ PDF2Image
 ├─ Requests
 └─ OpenPyXL
```

## 각 도구의 역할

### Python

전체 업무 흐름을 제어하는 엔진

### Streamlit

사용자가 클릭하는 화면

### Playwright

웹 브라우저 자동화

### Pandas

엑셀 데이터 처리

### PDF2Image

PDF → 이미지 변환

### Requests

외부 API 호출

### OpenPyXL

결과 엑셀 생성

## 최종 목표

```text
수료자 명단 업로드
 ↓
수료증 다운로드
 ↓
파일명 정리
 ↓
문자 발송
 ↓
결과 저장
```

단순 반복 업무를 클릭 몇 번으로 끝내는 것이 목표다.
